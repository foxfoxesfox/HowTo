# How To OSINT?

- OSINT (Open Source Intelligence) is the use of publicly available information to gather intelligence.
- Some use cases include:
    - Threat Intelligence
    - Reputation Checking
    - Vulnerability Mapping
    - Background Checking

| Tool | Website URL | Primary Field | Key Strengths |
|---|---|---|---|
| VirusTotal | https://www.virustotal.com/ | File & Website Reputation | Scans files and URLs using multiple antivirus engines to detect malware and assess domain reputation. |
| urlscan.io | https://urlscan.io/ | Website Intelligence | Analyzes URLs for malicious behavior and records the live HTTP transactions of the scanned site. |
| DNSDumpster | https://dnsdumpster.com/ | Domain Reconnaissance | Maps out DNS records, discovers hidden subdomains, and identifies host IP addresses. |
| Have I Been Pwned | https://haveibeenpwned.com/ | Account Verification | Cross-references email addresses against databases of known data breaches to track web compromises. |
| Namechk | https://namechk.com/ | Username Hunting | Quickly verifies the usage and availability of specific usernames across dozens of social media platforms. |
| ExifTool | https://exiftool.org/ | Image & File Metadata | Extracts hidden geolocation data, author information, and timestamps from documents and photographs. |
| Google Earth Pro | https://www.google.com/earth/about/versions/#earth-pro | Geolocation & Visuals | Provides 3D terrain mapping, historical imagery timelines, and distance measurements for visual verification. |
| SpiderFoot | https://www.spiderfoot.net/ | Automated Reconnaissance | Automates intelligence gathering by querying over 100 public data sources for IPs, domains, and emails. |
| Maltego CE | https://www.maltego.com/ | Link Analysis | Visually graphs complex relationships and network connections between individuals and organizations. |
| OSINT Framework | https://osintframework.com/ | Resource Directory | Acts as an indexed, web-based directory that categorizes hundreds of specific OSINT tools by their tasks. |
